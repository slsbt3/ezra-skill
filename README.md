# עזרא (ezra)

סקיל של Claude Code: איך שיחות פיתוח ("עובדים") עובדות מול עזרא, שיחת ניהול שמשמשת לוח בקרה.
הסקיל כללי, ומסביר רק איך עובדים. הוא כתוב בעברית, בשלושה קבצים:
- `SKILL.md`: מה שכל עובד צריך. Claude Code טוען אותו.
- `EZRA.md`: מה שרק עזרא עושה (הלוח, הכרטיס של עזרא, מד השימוש, שינוי בסקיל, מחשב חדש, מעבר חשבון ורשימת העובדים). עזרא קורא אותו מיד אחרי SKILL.md.
- `CHANGELOG.md`: היסטוריית הגרסאות.


**פרטי ההתקנה** (מי הבעלים, נתיבים, מחשבים, כתובות, כללי ייצור) נמצאים בקובץ פרטי אחד, `local.md`, בתיקיית עזרא של כל התקנה, ולא במאגר. ה־CLAUDE.md של המחשב מפנה אליו. הלוח נמצא כאן כתבנית, `board/board.html`, עם דוגמה לרשימת העובדים. כל התקנה מעתיקה אותו לתיקיית עזרא שלה, ומשנה בו רק את CONFIG. הכלים של כל התקנה לא נמצאים כאן.

## התקנה, בפעם הראשונה
1. מתקינים את הסקיל:
```
git clone <כתובת המאגר> "%USERPROFILE%\.claude\skills\ezra"
```
2. פותחים שיחה חדשה ב־Claude Code ומדביקים:
```
אתה עזרא, שיחת הניהול של כל שיחות הפיתוח שלי. קרא את הסקיל ezra ואת EZRA.md שבתיקייה שלו, ותעשה הפעלה ראשונה.
```
עזרא שואל כמה שאלות, אחת בכל פעם, ויוצר את תיקיית עזרא, את `local.md`, את רשימת העובדים ואת הלוח. ה־hook של העובדים והטיימר נכנסים רק אחרי "כן" שלך. הפירוט: EZRA.md, בסעיף "הפעלה ראשונה אצל בעלים חדש".

## מחשב נוסף
מתקינים את הסקיל באותה דרך, ומוסיפים ל־CLAUDE.md של המחשב שורה עם הנתיב ל־`local.md` שבתיקיית עזרא.

## מה יש במאגר
- `SKILL.md`, ‏`EZRA.md`, ‏`CHANGELOG.md`: הסקיל.
- `local.example.md`: תבנית לקובץ הפרטים של ההתקנה.
- `board/board.html`: הלוח, כולל תצוגת המשרד. ‏`board/projects.example.json`: דוגמה לרשימת העובדים.
- `hooks/ezra-hook.js`: ה־hook שמסמן עובד "עובד" ומזכיר לו לעדכן את הכרטיס.

## עדכון
```
git -C "%USERPROFILE%\.claude\skills\ezra" pull
```

## שינוי בסקיל
משנים את `SKILL.md`, או את `EZRA.md` כשזה משהו שרק עזרא עושה. מוסיפים שורה בראש `CHANGELOG.md`, בודקים שאין בקבצים פרטים של התקנה, ואז commit ו־push. בשאר המחשבים מריצים pull.
